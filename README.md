Файловый органайзер

Керезора Р.М. АСУбз-25-1

Сортировка файлов 

Утилита автоматически сортирует файлы в указанных папках (определяет тип каждого файла по его расширению и раскладывает их по соответствующим категориям).

Язык программирования с++, IDE visual studio 

Требования к запуску: 
- Windows (7, 8, 10, 11)
- Компилятор с поддержкой C++17
- Visual Studio 2019/2022 (рекомендуется)
  
Компиляция в Visual Studio:
1. Создайте новый проект → Консольное приложение 
2. Замените содержимое `main.cpp` на код из этого репозитория
3. В свойствах проекта установите C++ Language Standard: C++17
4. Нажмите Ctrl + Shift + B для компиляции
5. Запустите Ctrl + F5
   
Настройка кодировки (важно!)
Чтобы русские буквы отображались правильно, в свойствах проекта:
- C/C++ → Командная строка → Добавить: `/utf-8`
